## About me

I'm in the second year of a Master's in **Biometrics and Intelligent Systems** at Université Paris-Est Créteil. I completed M1 with honours (15/20) and hold a Bachelor's in Information Technology. My main interests are computer vision, machine learning and applied AI.

I like projects that work end to end: building a model, evaluating it with the right metrics instead of a single accuracy number, and deploying it behind an API or web interface that people can actually use.

## Featured projects

### 🔐 [Facial Biometrics System with LLM-Assisted Evaluation](https://github.com/Mr-Noman-Khan/Facial-Biometrics-llm)

A research-oriented face recognition web application supporting one-to-one verification and one-to-many identification.

- Full pipeline: face detection, alignment and feature extraction
- Evaluated with FAR, FRR, EER, ROC curves, and Rank-1 / Rank-k
- Robustness experiments tracked with MLflow
- An LLM layer that explains the performance metrics in plain language

`Python` · `Flask` · `FaceNet` · `MTCNN` · `OpenCV` · `MLflow`
