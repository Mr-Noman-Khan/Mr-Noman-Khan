## About me

I'm a software developer in the second year (M2) of a Master's in **Biometrics and Intelligent Systems** at Université Paris-Est Créteil. I completed M1 with honours (15/20), and I hold a Bachelor's in Information Technology.

I started as a developer, and that still shapes how I work. I like a model to end up inside an application that someone can open, use and trust, so I spend as much time on the code around it as on the model itself: the API, the interface, the experiment tracking, and the evaluation that tells you whether it really works.

## What I'm looking for

A **6-month internship starting January 2027** as a software, ML or AI engineer. I'm open to any domain: computer vision, biometrics, machine learning, LLM applications, data, or general software engineering. What matters to me is a team that builds things people actually use, where I can contribute to both the engineering and the AI side.

## How I build

- **Back to front.** Python backends with Flask and FastAPI, REST APIs, and front ends in React, HTML, CSS and JavaScript.
- **Measured, not guessed.** Experiments are tracked with MLflow and results are judged with proper metrics, not a single accuracy figure.
- **Version-controlled.** Everything lives in Git and GitHub, with the code public so you can read it.
